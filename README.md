# Python Programming Skills for Business Analytics I

**[Read the course online](https://hanisaf.github.io/python-programming-skills/)** · [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/hanisaf/python-programming-skills/main?urlpath=lab)

Course materials for **BUSN 3030E** at the Terry College of Business, University of Georgia.

The course introduces data analytics with Python: programming fundamentals, built-in data structures for storing and manipulating data, statistical analysis, and data visualization.

## How the materials are organized

Each of the 15 modules has two notebooks:

| Folder | Notebook | Purpose |
|---|---|---|
| [`lectures/`](lectures) | **Lecture** | Three parts. *Preparation* explains the concepts with runnable examples, *Warmup* checks understanding with short exercises, and *Workout* combines the concepts on a larger, usually real-world, problem. Exercises come with worked solutions. |
| [`drills/`](drills) | **Drill** | A graded problem set. Write your answers in the marked cells; expand the 💡 hints when you are stuck. Answers stored in `test_1`, `test_2`, … are checked by the [code tester](https://notebook-tester.safadi-puzzler.com/BUSN3030E). |

The lecture notebooks are the course readings: no external textbook is required. Work through the lecture first, then complete the drill.

## Getting started

The notebooks need **Python 3.12+** and **pandas 3.0+**. The simplest setup is the [Anaconda distribution](https://www.anaconda.com/download). To install the required packages into an existing environment:

```bash
pip install -r requirements.txt
```

Every notebook loads its data from this repository over the web, so a notebook runs on its own: download it, open it in Jupyter, and run it. No data files need to be copied.

**Read online.** Every lecture and drill is published as a web page at [https://hanisaf.github.io/python-programming-skills/](https://hanisaf.github.io/python-programming-skills/). The pages need no installation, but the code cannot be run there.

**Run in the browser with Binder.** Click the *launch binder* badge at the top of this page, or [this link](https://mybinder.org/v2/gh/hanisaf/python-programming-skills/main?urlpath=lab), to open the whole repository in JupyterLab with every package preinstalled; nothing to install on your computer. The first launch can take a few minutes while Binder builds the environment. Binder sessions are temporary: download any notebook you want to keep (*File → Download*) before closing the tab.

To run a notebook in Google Colab instead, open it on GitHub and replace `github.com` with `githubtocolab.com` in the address. If the Colab environment has an older pandas, run `%pip install -U "pandas>=3"` in the first cell, then restart the session.

## Data

The [`data/`](data) folder holds the datasets used in the course. Notebooks read them with

```python
DATA_URL = "https://raw.githubusercontent.com/hanisaf/python-programming-skills/main/data/"
df = pd.read_csv(DATA_URL + "gapminder.tsv", sep="\t")
```

Some modules also use the example datasets that ship with [seaborn](https://github.com/mwaskom/seaborn-data) and [statsmodels](https://www.statsmodels.org/stable/datasets/index.html).
