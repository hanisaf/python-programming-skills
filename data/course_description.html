BUSN 3030E: Python Programming Skills for Business Analytics I

Description

Introduces students to data analytics with the Python programming language. Covers programming fundamentals and focuses on built-in data structures for storing and manipulating data, statistical analysis, and data visualization.

Learning outcomes

  • The Python ecosystem for data analytics
  • Python language fundamentals
  • Data representation and data manipulation in Python
  • Data visualization and statistical analysis in Python
